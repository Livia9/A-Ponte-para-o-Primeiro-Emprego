# contrata talento
Baseado na ODS 4.4, Esse protótipo apresentaria, em tese, uma solução para uma ponte para o primeiro emprego entre jovens e empresas, um site que permite o acesso mais direto entre usuários possivelmente alunos ou formandos com o que as empresas buscam para contratar funcionários com um design moderno e cursos práticos para garantir a sonhada experiência.
